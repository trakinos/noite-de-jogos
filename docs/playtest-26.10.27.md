# Dono do Bairro — Playtest 2026-10-27

Notes from the first real playtest of Dono do Bairro. "DRDB" below is the Deu Ruim / Deu Bom deck (renamed to Tigrinho).

## Improvements

- [x] The current player should be shown bigger on the board (also on phones).
- [x] Make the player movement a little slower.
- [ ] Rolling doubles gets an animation, so the moment feels meaningful.
- [ ] Arrest animation: a little cop catches the player and takes them to jail.
- [ ] Animations for when the current player is arrested and when bail is paid.
- [ ] Animation for drawing a DRDB card (see the Feira code for a similar animation).
- [ ] Show the DRDB card to everyone, colored for good or bad.
- [ ] During a trade, show the values of the properties in the proposal.
- [ ] Counter-proposal in trades.
- [ ] Redo the board tiles: the group color detail always faces the center of the board (as it does now on the bottom row), and the whole tile gets a soft tint of the owner's color.
- [ ] Show the current rent on each tile.
- [ ] Click a player in the players list to see their properties.
- [x] Dice with pips instead of numerals.
- [x] If possible, a dice-rolling animation.

## Renames

- [x] DRDB → **Tigrinho** (the Brazilian betting game).
- [x] Sorveteiro → **Carro da Pamonha** (the Sorveteria is right beside it, so it needed something different).
- [x] Ponto de Ônibus → **Pé de Meia**.
- [x] Xilindró → **Papuda** (a prison in Brazil).

## Extra settings (changeable in the lobby before the game starts)

- [ ] Trades are shown to everyone, not just the players involved.
- [ ] Game acceleration (brainstorm later).

## Custom rules (toggle custom rules, then pick from a list — not yet to be developed)

- [ ] Shuffle the properties, so streets of the same group may not sit together (streets only, not services or other squares).
- [ ] Objective cards (maybe for ending the game, maybe for rewards).
- [ ] Shuffle the property values (streets only) and hide them, so a value is only known once someone lands on it.
- [ ] Wildcards in the Tigrinho deck that really play with luck, such as a forced trade or a forced mortgage (brainstorm later).
